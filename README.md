# 🎓 Student Management System

A modern **Student Management System** built using **Flask, SQLite, and Tailwind CSS** with a clean cyber-style UI.

---

## 🚀 Features

* 🔐 Secure Admin Authentication (Password Hashing)
* 👨‍🎓 Student Management (Add, View, Edit)
* 💰 Fee Tracking System
* 🔄 Password Reset System
* 🎨 Modern UI (Tailwind + Glassmorphism)

---

## 🛠️ Tech Stack

* Backend: Flask (Python)
* Database: SQLite
* Frontend: HTML, Tailwind CSS
* Security: Werkzeug (Password Hashing)

---

## 📂 Project Structure

```
project/

├── app.py

```

## ⚙️ Setup Instructions

```bash
git clone https://github.com/YOUR_USERNAME/student-management-system.git
cd student-management-system

pip install -r requirements.txt

python app.py
```
